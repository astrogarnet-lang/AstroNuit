# TimeControl

Локальное Android-приложение для учёта участников и фактического рабочего времени.

## Текущий статус

Начальная рабочая версия v0.1: тёмная тема, пять разделов, управление участниками, архивирование/мягкое удаление, SQLite, отметки прихода/ухода, защита от повторного открытия сессии, обзор текущих открытых сессий.

Это не финальная v1.0. Календарь, редактирование исторических отметок, перерывы, действия/заметки, расширенная статистика, экспорт и резервное копирование входят в следующие этапы.

## Запуск локально

Требуется Flutter stable и Android SDK.

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

## Сборка APK

```bash
flutter build apk --release
```

## Автоматическая сборка через GitHub

1. Создайте пустой GitHub-репозиторий.
2. Один раз добавьте файл `.github/workflows/build-apk.yml` из комплекта.
3. Загрузите `TimeControl_Source.zip` в корень репозитория и отправьте commit.
4. Workflow распакует ZIP, соберёт APK, опубликует APK как Artifact и удалит исходный ZIP из Git-репозитория отдельным commit.

Важно: GitHub Actions не запускает workflow из файла, который находится только внутри загружаемого ZIP. Поэтому workflow нужно установить в репозиторий один раз заранее.

## Данные

SQLite-файл приложения хранится в приватном каталоге Android-приложения. Удаление приложения Android может удалить локальную базу. Перед будущими переносами используйте резервное копирование (будет реализовано на этапе v0.7).
