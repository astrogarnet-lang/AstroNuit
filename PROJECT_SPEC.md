# TimeControl — спецификация

Исходное ТЗ пользователя от 2026-11-03 является нормативным документом проекта. Цель: автономное Android-приложение Flutter/Dart с SQLite для максимум 200 участников.

## Ключевое правило времени
Свободный график. Записывается только фактический приход и уход. Никаких автоматических опозданий относительно 09:00. Поддерживаются несколько сессий за день, переход через полночь и ручные корректировки в целевой версии.

## Архитектура
- UI: Flutter Material 3, тёмная тема, изумрудный акцент.
- Хранилище: SQLite через sqflite.
- Все даты/время сохраняются как Unix epoch milliseconds; отображение — локальное время устройства.
- История не удаляется каскадно при мягком удалении участника.
- Изменения фиксируются в audit_log.
