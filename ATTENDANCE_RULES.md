# Правила посещаемости и рабочего времени

- Используется свободный график; 09:00–18:00 не является обязательным расписанием.
- «Пришёл» сохраняет фактический момент нажатия.
- «Ушёл» закрывает существующую открытую сессию.
- Одновременно допускается не более одной открытой сессии на участника.
- Несуществующую сессию закрыть нельзя.
- Отрицательная продолжительность запрещена.
- Продолжительность завершённой сессии равна check_out - check_in.
- Для дневной агрегации сессия должна пересекаться с локальными границами выбранного дня; длительность пересечения учитывается в соответствующем дне.
- Переход через полночь допустим.
- Автоматическое опоздание не рассчитывается.
- Все временные отметки хранятся в epoch milliseconds; часовой пояс применяется при отображении и определении локальных календарных границ.
